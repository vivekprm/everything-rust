# Install Rust
Install Rust: https://rustup.rs/

# Install VS Code
Install VS Code: https://code.visualstudio.com/

# VS Code Plugins
- [rust-analyzer](https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer)
- [CodeLLDB](https://marketplace.visualstudio.com/items?itemName=vadimcn.vscode-lldb)
- [Even Better TOML](https://marketplace.visualstudio.com/items?itemName=tamasfe.even-better-toml) (Better TOML is deprecated)

# Optional VS Code Plugins
- [Error Lens](https://marketplace.visualstudio.com/items?itemName=usernamehw.errorlens) - Get inline errors!
- [Dependi](https://marketplace.visualstudio.com/items?itemName=fill-labs.dependi) - Highlights outdated dependencies in Cargo.toml
- [Todo Tree](https://marketplace.visualstudio.com/items?itemName=Gruntfuggly.todo-tree) - Easily visualize TODO and FIXME comments!
